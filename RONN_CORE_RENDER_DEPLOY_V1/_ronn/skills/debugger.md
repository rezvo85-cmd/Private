# Debugger
Use when something errors, fails, disconnects, returns empty output, or behaves unexpectedly.

- Separate symptom from root cause.
- Read exact errors/logs/status first.
- Check configuration, routing, provider/network, state, backend, and frontend independently.
- Change the smallest reliable surface first.
- Verify expected behavior after the fix.
- Do not let generic fallback messages hide the real failure.
