Client header: X-RONN-Client: <stable-client-id>

Optional Core auth: Authorization: Bearer <RONN_CORE_TOKEN>

ACCOUNT/SYNC NOTE
Desktop and the included mobile client use the same personal account id so projects/memory/tasks can sync through one Core. That header is not a security credential. A public multi-user deployment must replace header-trusted account selection with authenticated server-side accounts.

IMPORTANT PRODUCTION BOUNDARY
Core is cloud-ready, not cloud-hosted by this ZIP. A public deployment still needs HTTPS, account auth, secrets management, rate limiting, production database/backup policy and mobile signing/release infrastructure.
